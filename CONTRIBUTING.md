# 🤝 Contribuer à DiabetoWeb

Merci de votre intérêt pour **DiabetoWeb** !  
Ce projet vise à aider les médecins dans le diagnostic précoce du diabète grâce à une application web sécurisée et un modèle de Machine Learning.  
Vos contributions sont les bienvenues pour améliorer le projet. 🚀

---

## 📝 Comment contribuer

### 1. Fork & Clone
- Forkez le dépôt.
- Clonez votre fork localement :
```bash
git clone https://github.com/[votre-utilisateur]/DiabetoWeb-Project.git
cd DiabetoWeb-Project
```

### 2. Créer une branche
- Utilisez une nouvelle branche pour vos modifications :
```bash
git checkout -b feature/ma-nouvelle-fonctionnalite
```

### 3. Faire vos modifications
- Assurez-vous que le code respecte les standards du projet (PEP8 pour Python).
- Ajoutez des commentaires clairs et de la documentation si nécessaire.

### 4. Commit & Push
- Faites un commit clair et concis :
```bash
git commit -m "✨ Ajout : nouvelle fonctionnalité X"
```
- Poussez votre branche vers votre fork :
```bash
git push origin feature/ma-nouvelle-fonctionnalite
```

### 5. Pull Request
- Ouvrez une Pull Request (PR) vers la branche `main` du projet.
- Décrivez les changements apportés et mentionnez les issues associées si elles existent.

---

## 📌 Bonnes pratiques

- ✅ Suivre les conventions de nommage (`snake_case` pour Python).  
- ✅ Ajouter des tests unitaires si vous modifiez la logique critique (ex. prédiction ML).  
- ✅ Mettre à jour la documentation (`README.md`) si nécessaire.  
- ✅ Éviter les commits trop généraux comme "fix bug". Préférez des messages clairs : `fix: correction authentification bcrypt`.

---

## 🛠️ Stack technique (rappel)

- **Backend** : FastAPI  
- **Frontend** : HTML, CSS, Jinja2  
- **Base de données** : PostgreSQL  
- **Machine Learning** : scikit-learn, joblib  
- **Sécurité** : Passlib (bcrypt)  
- **Serveur** : Uvicorn
